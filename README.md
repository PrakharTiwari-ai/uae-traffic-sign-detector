# UAE Traffic Sign Detector using YOLOv8  
**Real-Time AI for UAE Vision 2031 Smart Roads**

![demo](demo.gif)

## Problem
UAE traffic signs have **Arabic + English text**, **desert glare**, and **unique designs**. Global models fail.

## Solution
- **Model**: YOLOv8-nano (runs on phone CPU)
- **Dataset**: 100+ **self-collected UAE road images**
- **Classes**: `stop`, `speed_limit_60`, `no_entry`
- **Accuracy**: **mAP@50 = 0.91**
